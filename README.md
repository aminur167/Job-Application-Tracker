# Job Application Tracker Dashboard

A streamlined browser application to help software job seekers organize, track, and monitor their application pipeline through all recruitment stages.

## Features

- **Stage Tracking**: Organize positions by status: *Wishlist*, *Applied*, *Interview*, *Offered*, *Rejected*.
- **Quick Entry Modal**: Add company name, role, salary range, application link, and submission date.
- **Live Search & Filter**: Instant filtering by company name or application status.
- **Data Persistence**: Uses browser LocalStorage so records remain intact across browser sessions.

## Tech Stack

- **HTML5**: Semantic UI structure
- **CSS3**: Custom responsive styling, status badge color-coding
- **JavaScript**: Vanilla ES6+ DOM manipulation and LocalStorage management
